## Pauli strings

The Pauli group on $n$ qubits consists of tensor products of $I, X, Y, Z$, with an overall phase $\pm1$ or $\pm i$. A **Pauli string** such as $Z_1Z_2 = ZZI$ lists one Pauli per qubit. This lesson has no circuit, so the string is read left to right as qubits 1, 2, 3 (the Qiskit ordering of the earlier lessons does not apply).

Two Paulis on the same qubit anticommute when both differ from $I$ and differ from each other: $XZ = -ZX$. On different qubits they commute. Two Pauli strings therefore commute when they anticommute on an even number of positions, and anticommute when that number is odd:

$$
ZZI \text{ and } XII:\ 1 \text{ position (qubit 1)} \Rightarrow \text{anticommute}, \qquad ZZI \text{ and } XXI:\ 2 \text{ positions} \Rightarrow \text{commute}.
$$

## Stabilizer codes

A **stabilizer group** $S$ is an abelian subgroup of the Pauli group that does not contain $-I$. It is generated by a few commuting Pauli strings $g_1, \dots, g_m$, the **generators**. The **code space** is the set of states fixed by all of $S$:

$$
\mathcal{C} = \{\,|\psi\rangle : g_i|\psi\rangle = |\psi\rangle \text{ for every } i\,\}.
$$

With $m$ independent generators on $n$ qubits, the code space has dimension $2^{n-m}$, so it encodes $k = n - m$ qubits.

The three-qubit bit-flip code has $n=3$ and generators $g_1 = Z_1Z_2$, $g_2 = Z_2Z_3$. Both fix $|000\rangle$ and $|111\rangle$, and $k = 3 - 2 = 1$. The code space is $\mathrm{span}\{|000\rangle, |111\rangle\}$, the same code as in lesson 4.2, now described by what it satisfies instead of by how it is built.

## Syndrome

Let $E$ be a Pauli error and $|\psi\rangle$ a code state. Since $E$ either commutes or anticommutes with $g_i$,

$$
g_i\,E|\psi\rangle = \pm\,E\,g_i|\psi\rangle = \pm\,E|\psi\rangle,
$$

with $+$ if $E$ commutes with $g_i$ and $-$ if it anticommutes. The damaged state $E|\psi\rangle$ is an eigenstate of each generator, with eigenvalue $(-1)^{s_i}$. Measuring the generators gives the bits $s_i$, the **syndrome**, without learning anything about $|\psi\rangle$ itself. For the bit-flip code:

| Error | $Z_1Z_2$ | $Z_2Z_3$ | Syndrome |
| :-- | :-- | :-- | :-- |
| $X_1$ or $Y_1$ | anticommutes | commutes | (1, 0) |
| $X_2$ or $Y_2$ | anticommutes | anticommutes | (1, 1) |
| $X_3$ or $Y_3$ | commutes | anticommutes | (0, 1) |
| $Z_1$, $Z_2$ or $Z_3$ | commutes | commutes | (0, 0) |

This is the table of lesson 4.2. The code corrects X (and Y) errors on one qubit, and the table shows what it misses: Z errors have the trivial syndrome.

## Logical operators

An operator that commutes with every generator preserves the code space. If it is not in $S$, it changes the encoded state, and it is a **logical operator**. For the bit-flip code:

$$
\bar X = X_1X_2X_3, \qquad \bar Z = Z_1 .
$$

$\bar X$ maps $|000\rangle \leftrightarrow |111\rangle$, and $\bar Z$ gives $+1$ on $|000\rangle$ and $-1$ on $|111\rangle$. They anticommute, as $X$ and $Z$ do on one qubit. $Z_2$ and $Z_3$ are equivalent to $Z_1$, since they differ from it by a generator.

An error $E$ falls into one of three classes. If it anticommutes with some generator, the syndrome is non-trivial and it can be detected. If it commutes with all generators and lies in $S$, it acts trivially on the code space. If it commutes with all generators and is not in $S$, it is a logical operator: the error is undetectable and corrupts the encoded qubit. The **distance** of a code is the weight (number of non-identity positions) of its shortest logical operator. Here it is 1 for $\bar Z$, which is why the code protects only against bit flips.

## Larger codes

The same rules apply to any list of generators. The five-qubit code has $n=5$, $m=4$ and generators $XZZXI$, $IXZZX$, $XIXZZ$, $ZXIXZ$ (cyclic shifts of $XZZXI$). Each of its 15 single-qubit errors gives a different non-trivial syndrome, so it corrects any single-qubit error.
