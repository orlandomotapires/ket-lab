## Reading the syndrome without a circuit

In lessons 4.2 and 4.3 the syndrome came from following an error through a circuit. That works for three qubits and becomes painful for nine. There is a shortcut that uses only the checks themselves. Take the check $Z_1Z_2 = ZZI$ and the error $X$ on the first qubit, $XII$. Since $XZ=-ZX$, applying the error before or after the check differs by a sign, so a state that satisfied the check with $+1$ now gives $-1$. The check noticed the error. An error on the third qubit, $IIX$, commutes with $ZZI$ and passes unseen. Everything below is bookkeeping around that single observation.

This lesson has no circuit, so a Pauli string is read left to right as qubits 1, 2, 3, and the Qiskit ordering of the earlier lessons does not apply.

## Pauli strings and when they commute

A **Pauli string** such as $ZZI$ lists one of $I, X, Y, Z$ per qubit. Two Paulis on the same qubit anticommute when both differ from $I$ and from each other, and commute otherwise; on different qubits they always commute. Two strings therefore commute when they anticommute on an even number of positions, because the signs multiply.

$ZZI$ and $XII$ clash at one position, so they anticommute. $ZZI$ and $XXI$ clash at two, so they commute. A longer one: $XYZ$ and $ZYX$ clash at positions 1 and 3, and $Y$ meets $Y$ at position 2 without a clash, so the strings commute. The slip is to count $Y$ against $Y$ as a clash.

## Stabilizer codes

A **stabilizer group** $S$ is an abelian group of Pauli strings that does not contain $-I$. It is generated by a few commuting strings $g_1,\dots,g_m$, the **generators**, and the **code space** is the set of states fixed by all of $S$:

$$
\mathcal{C} = \{\,|\psi\rangle : g_i|\psi\rangle = |\psi\rangle \text{ for every } i\,\}.
$$

With $m$ independent generators on $n$ qubits the code space has dimension $2^{n-m}$, so the code encodes $k=n-m$ qubits. The bit-flip code has $n=3$ and generators $ZZI$ and $IZZ$. Both fix $|000\rangle$ and $|111\rangle$, so $k=3-2=1$ and the code space is $\mathrm{span}\{|000\rangle,|111\rangle\}$: the code of lesson 4.2, described now by what it satisfies instead of how it is built.

## Syndrome

Let $E$ be a Pauli error and $|\psi\rangle$ a code state. Since $E$ commutes or anticommutes with each generator,

$$
g_i\,E|\psi\rangle = \pm\,E\,g_i|\psi\rangle = \pm\,E|\psi\rangle ,
$$

with $+$ when $E$ commutes with $g_i$ and $-$ when it anticommutes. The damaged state is an eigenstate of every generator with eigenvalue $(-1)^{s_i}$, and measuring the generators gives the bits $s_i$, the **syndrome**, without learning anything about $|\psi\rangle$.

For the bit-flip code, $Y$ on the middle qubit, $IYI$, anticommutes with both $ZZI$ and $IZZ$: the syndrome is $(1,1)$, the same as $X$ on the middle qubit. $XII$ and $YII$ give $(1,0)$ and $IIX$, $IIY$ give $(0,1)$. Any $Z$ commutes with both generators and gives $(0,0)$, which is the blind spot of the code.

The same rule needs no new idea for bigger codes. The five-qubit code has generators $XZZXI$, $IXZZX$, $XIXZZ$, $ZXIXZ$ (cyclic shifts of the first). The error $XIIII$ commutes with the first and the third, which also start with $X$, and with the second, which starts with $I$, and anticommutes only with $ZXIXZ$: syndrome $(0,0,0,1)$. $ZIIII$ gives $(1,0,1,0)$ and $YIIII$ gives $(1,0,1,1)$. All 15 single-qubit errors give different non-zero syndromes, which is why this code corrects any error on one qubit with only five qubits.

## Logical operators and distance

An operator that commutes with every generator preserves the code space. If it is not in $S$, it changes the encoded state: it is a **logical operator**. The bit-flip code has

$$
\bar X = XXX, \qquad \bar Z = ZII .
$$

$\bar X$ exchanges $|000\rangle$ and $|111\rangle$, and $\bar Z$ gives $+1$ on $|000\rangle$ and $-1$ on $|111\rangle$. They anticommute, as $X$ and $Z$ do on one qubit. $IZI$ and $IIZ$ are equivalent to $\bar Z$, since each differs from it by a generator.

So an error falls in one of three classes. If it anticommutes with some generator, it shows in the syndrome. If it commutes with all of them and lies in $S$, it acts as the identity on the code space. If it commutes with all of them and is not in $S$, it is a logical operator: invisible and harmful. The **code distance** is the weight (number of non-identity positions) of its shortest logical operator. For the bit-flip code it is 1, because of $\bar Z$, which is why the code protects against bit flips only.
